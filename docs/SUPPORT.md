# Support information

Replace these placeholders before production or Play submission:

- Support email: `support@your-domain.tld`
- Privacy email: `privacy@your-domain.tld`
- Support website: `https://your-domain.tld/support`
- Service status: `https://status.your-domain.tld`

Support requests should include company name, affected role, UTC time, request ID from the response,
and a description without passwords, tokens, signing files, or unnecessary employee documents.
Urgent security reports should use the private security contact and include reproduction details.
