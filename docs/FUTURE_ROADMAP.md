# Future roadmap

1. Select and integrate a regional payment provider through the existing adapter.
2. Add Firebase push transport with per-device tokens and delivery telemetry.
3. Add a restricted Google Maps branch picker while retaining server-side geofence validation.
4. Move protected files to private object storage with short-lived authorized downloads and malware
   scanning.
5. Move exports and scheduled notifications to a durable queue; add Redis distributed rate limits.
6. Add full offline synchronization with conflict resolution.
7. Add payroll, ERP, and HR integrations through audited connectors.
8. Add iOS release support and App Store privacy metadata.
9. Consider server-side identity verification only after legal, biometric-consent, liveness, and
   accuracy requirements are approved.
