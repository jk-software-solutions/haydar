# DawamTech | Portfolio Summary

## Suggested title

Multi-tenant Attendance and Workforce Operations Platform — Flutter, Next.js and FastAPI

## Summary

**DawamTech** is an Arabic/English workforce operations SaaS built for multi-branch companies. It combines a role-aware Flutter mobile app with a responsive Next.js web portal and a FastAPI/PostgreSQL backend.

## Core capabilities

- GPS, authorized Wi-Fi and QR attendance verification.
- Branch geofencing, shifts, grace periods and employee assignments.
- Role-aware mobile workspaces for owners, managers, supervisors, HR and employees.
- Tasks, comments, receipt attachments, permissions, leave requests and approvals.
- In-app, push and opt-in email notifications, including password recovery.
- Arabic RTL and English LTR web/mobile experiences.
- Branded PDF and Excel exports for attendance and operational reports.
- Platform administration for subscription plans, limits and tenant operations.

## Technology stack

- **Mobile:** Flutter, Dart, Riverpod, GoRouter, Dio, Firebase Messaging, Geolocator, Mobile Scanner and secure device storage.
- **Web:** Next.js 16, React 19, TypeScript, React Hook Form, Zod, TanStack Query and Tailwind CSS.
- **Backend:** Python 3.12, FastAPI, async SQLAlchemy, PostgreSQL, Alembic, JWT, Argon2, Firebase Admin, SMTP, ReportLab and OpenPyXL.
- **Operations:** Nginx/TLS, system services, scheduled maintenance and tenant-aware authorization.
