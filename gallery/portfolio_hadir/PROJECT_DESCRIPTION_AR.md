# DawamTech | دوام تك

## عنوان مقترح للمشروع في مستقل

تطوير منصة حضور وانصراف وإدارة موظفين متعددة الفروع — تطبيق Flutter ولوحة تحكم ويب

## الوصف المختصر

**DawamTech | دوام تك** منصة عربية/إنجليزية لإدارة الحضور والانصراف والموظفين والفروع والورديات. تجمع بين تطبيق جوال عملي للموظف والمدير ولوحة تحكم ويب متجاوبة للشركة ومالك المنصة، مع توثيق الحضور عبر GPS أو شبكة Wi-Fi أو رمز QR، وتقارير PDF وExcel وإشعارات فورية.

## الوصف الكامل الجاهز للنشر

طورت منصة **DawamTech | دوام تك** كنظام SaaS لإدارة حضور الموظفين والعمليات اليومية للشركات متعددة الفروع. صممت التجربة لتكون سهلة للموظف على الجوال، وواضحة لمالك الشركة والمدير من تطبيق الجوال ولوحة الويب.

يستطيع الموظف تسجيل الحضور والانصراف من خلال الموقع الجغرافي GPS، أو شبكة Wi-Fi المعتمدة للفرع، أو رمز QR. ويتحقق الخادم من الفرع والوردية والوقت والصلاحية والنطاق قبل اعتماد العملية. كما يستطيع المدير متابعة الحضور، إدارة المهام، استقبال الاستئذانات والإجازات، ومراجعة التنبيهات والتقارير من مكان واحد.

يدعم المشروع عدة شركات داخل نفس المنصة، مع عزل بيانات كل شركة وصلاحيات مستقلة للمالك والمدير والمشرف والموارد البشرية والموظف. كما يتضمن إدارة الفروع والورديات، وربط الموظف بفرع ووردية، وإدارة باقات الاشتراك، والتقارير القابلة للتصدير، والملفات والمرفقات، والإشعارات داخل التطبيق والإشعارات الفورية والبريد الإلكتروني.

## أبرز الوظائف المنفذة

- تطبيق جوال واحد بحسب الدور: مالك، مدير، مشرف، موارد بشرية، أو موظف.
- لوحة ويب عربية وإنجليزية لإدارة الشركة ومالك المنصة.
- حضور وانصراف موثق عبر GPS وWi-Fi وQR.
- نطاق جغرافي للفروع مع خريطة، نصف قطر حضور، وعنوان مختصر للفرع.
- فروع وورديات وفترات سماح وربط موظفين بالفروع والورديات.
- حضور عن بُعد وقواعد إغلاق الوردية والتنبيه إلى التأخر أو نسيان الحضور.
- مهام للموظفين، حالات إنجاز، طلب تمديد، تعليقات، ومرفقات للصور والوثائق والملفات الصوتية.
- طلبات استئذان وإجازة ومتابعة الموافقات من المدير أو المشرف.
- مركز إشعارات، عدّاد غير المقروء، تنبيهات فورية، وإرسال البريد عند تفعيل تفضيل المستخدم.
- استعادة كلمة المرور عبر البريد الإلكتروني من التطبيق أو الموقع.
- تقارير حضور وانصراف واستئذانات وإجازات ووثائق ومهام، مع تصدير PDF وExcel.
- هوية الشركة في التقارير: الاسم والشعار وبيانات التواصل والسجل/الرقم الضريبي عند توفرها.
- إدارة اشتراكات وباقات وحدود الفروع والموظفين من لوحة مالك المنصة.
- واجهة RTL عربية وواجهة LTR إنجليزية مع تصميم متجاوب للجوال والويب.

## التقنيات المستخدمة

### تطبيق الجوال

- Flutter وDart.
- Riverpod لإدارة الحالة.
- GoRouter للتنقل والمسارات.
- Dio للتعامل مع واجهات API.
- Flutter Secure Storage لحماية رموز الجلسة محليًا.
- Geolocator لتحديد الموقع والحضور الجغرافي.
- Mobile Scanner لمسح رموز QR.
- Local Auth للتحقق الحيوي الاختياري على الجهاز.
- Firebase Core وFirebase Messaging للإشعارات الفورية.
- File Selector للمرفقات وUrl Launcher لروابط التواصل.

### لوحة الويب

- Next.js 16 وReact 19 وTypeScript.
- App Router ومسارات عربية/إنجليزية.
- React Hook Form وZod للتحقق من النماذج.
- TanStack React Query لإدارة بيانات الواجهة.
- Tailwind CSS لتنسيق واجهة متجاوبة.

### الخادم والبيانات

- Python 3.12 وFastAPI.
- SQLAlchemy Async وPostgreSQL.
- Alembic لترحيلات قاعدة البيانات الآمنة.
- JWT وArgon2 لتسجيل الدخول وحماية كلمات المرور.
- Firebase Admin لإرسال الإشعارات الفورية.
- SMTP لاستعادة كلمات المرور ونسخ الإشعارات عبر البريد.
- ReportLab وOpenPyXL لإنتاج تقارير PDF وExcel.
- نظام ملفات محمي للمرفقات مع تحكم في الصلاحيات والملكية.

### التشغيل والحماية

- بنية متعددة الشركات مع عزل بيانات وصلاحيات حسب الشركة والدور.
- واجهات API تتحقق من الصلاحيات على الخادم، وليس فقط من الواجهة.
- سجل تدقيق للعمليات الحساسة، وحدود للاشتراكات، ومهام صيانة مجدولة.
- Nginx وTLS وخدمات نظام لإدارة تشغيل الويب والـ API في بيئة الإنتاج.

## قيمة المشروع للعميل

يوفر النظام بديلاً موحدًا للسجلات اليدوية وتطبيقات الحضور المنفصلة، ويمنح الشركة رؤية أوضح لمن حضر أو تأخر أو خرج من النطاق، مع أدوات تشغيل يومية للمهام والطلبات والتقارير. كما أن تعدد القنوات — الجوال والويب والبريد والإشعارات — يجعل المتابعة أسرع وأسهل للإدارة والموظفين.
